# ShopProject — учебный интернет-магазин

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина: главная страница, каталог, карточка товара, оформление заявки и контакты. Сайт выполнен без CSS-фреймворков.

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров (9 карточек) с фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и FAQ;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — изображения (`product.jpg` — фото товара, `preview.jpg` — превью для Open Graph);
- `sitemap.xml` — карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Страницы сайта

| Страница | Содержание |
|---|---|
| `index.html` | hero-блок, преимущества, популярные товары, отзывы, модальное окно заявки |
| `catalog.html` | блок фильтров (sticky) и сетка карточек товаров |
| `product.html` | изображение, описание, цена, таблица характеристик, кнопка заявки |
| `order.html` | форма оформления заявки |
| `contacts.html` | контактная информация, ссылка на форму заявки, FAQ |

## Реализованные требования КР №1

- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация на всех страницах, активный пункт меню, якорные ссылки, хлебные крошки;
- карточки товаров (`article.product-card`) в сетке CSS Grid;
- таблица характеристик с `caption`, `thead`, `tbody`, `th`, `td`;
- форма заявки на `order.html` и в модальном окне `<dialog>` на главной странице;
- CSS-переменные, состояния `:hover` и `:focus-visible`;
- Flexbox (меню, карточки, кнопки) и CSS Grid (сетки товаров и отзывов, каталог, карточка товара);
- БЭМ-именование классов;
- позиционирование: `relative` и `absolute` (бейджи на карточках), `sticky` (закреплённая шапка на всех страницах, фильтр каталога), `fixed` и `z-index` (кнопка «Наверх»).

## Самостоятельные доработки

- **Варианты карточек через БЭМ-модификаторы**: `product-card--hit` и `product-card--discount` с бейджами «Хит» и «Скидка» (`position: absolute`), у карточки со скидкой цена выделена красным.
- **Sticky-фильтр каталога**: блок фильтров остаётся на экране при прокрутке списка товаров (`position: sticky`).
- **Расширенная таблица характеристик** на `product.html`: 11 параметров, выделенная шапка, подсветка строки при наведении.
- **Более подробная карточка товара**: изображение с бейджем, категория, наличие, список преимуществ, описание, блок «Доставка и оплата», кнопки заявки и возврата в каталог.
- **Блок отзывов** на главной странице: карточки `review-card` в сетке Grid.
- **Блок FAQ** на странице контактов: вопросы на `details`/`summary`, раскрываются без JavaScript.
- **Фиксированная кнопка «Наверх»** на всех страницах (`position: fixed`, `z-index`).
- **Подробный README.md** с описанием структуры, страниц и способа проверки.

## Как посмотреть проект

1. Открыть ссылку GitHub Pages (ниже) или скачать репозиторий.
2. Локально — открыть `index.html` в браузере, сервер не нужен.
3. Перейти по страницам через меню, проверить якоря «Преимущества», «Популярные товары», «Обратная связь».
4. На главной нажать «Заказать» — откроется модальное окно заявки.
5. В каталоге нажать «Подробнее» — откроется карточка товара; кнопка «Оформить заявку» ведёт на форму.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (модификаторы `--hit`, `--discount`);
- `product-details` — подробная карточка товара;
- `product-table` — таблица характеристик;
- `reviews`, `review-card` — отзывы;
- `faq` — часто задаваемые вопросы;
- `scroll-top` — кнопка «Наверх»;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.
